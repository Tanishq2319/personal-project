# Shreya – Interactive Memory Website
**Project Codename:** OYEE
**Version:** 1.0
**Goal:** Create a cinematic, premium, emotional interactive website that feels like reliving memories rather than browsing a webpage.

---

# 1. Vision

This is **not** a love confession website.

This is **not** a portfolio.

This is **not** a slideshow.

It is an **interactive memory film** that celebrates our journey, the moments we shared, and how much those moments still matter after Shreya moved to the USA.

The website should make her smile, laugh, remember, become emotional, and hopefully cry—not because she feels guilty, but because she realizes how deeply someone cherished every little moment.

At the end, she should think:

> "He remembered everything."

---

# 2. Core Emotion

Primary Emotion
- Nostalgia

Secondary Emotions
- Warmth
- Comfort
- Happiness
- Missing someone
- Hope
- Bittersweet love

Never make the experience feel like emotional pressure.

The website should say:

> "I wanted you to have this."

Not:

> "Please come back."

# 14. Emotional Rules

Never guilt-trip.

Never manipulate.

Never say

"You left me."

Instead

"You left for your dreams."

Respect her journey.

Celebrate her growth.

The website is built with admiration.

Not expectation.

---

# 15. Final Message Philosophy

The ending should hint.

Not confess again.

The feeling should be

"I still care."

Not

"Please love me."
